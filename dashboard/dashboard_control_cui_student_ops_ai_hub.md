# Dashboard de Control – CUI Student Ops AI Hub

## Objetivo

Este documento registra la evidencia del dashboard de control del proyecto **CUI Student Ops AI Hub**, desarrollado como parte de la entrega final **Ecosistema IA Autónomo para Negocios**.

El dashboard permite monitorear el estado general del flujo de automatización, medir el volumen de consultas procesadas, visualizar casos aprobados por revisión humana y controlar la tasa de errores del sistema.

## Vista pública compartida

Airtable Shared View del dashboard de métricas:

https://airtable.com/appv4HQuLoznGMA1Z/shr6pjBuPnE5lzkuR

## Tabla utilizada

**Métricas Dashboard**

Esta tabla funciona como panel de control operativo del ecosistema. Resume los indicadores principales de la prueba final y permite verificar el estado del sistema sin acceder a toda la base de datos.

## KPIs incluidos

- Total de consultas
- Consultas procesadas por IA
- Consultas en revisión humana
- Consultas aprobadas
- Consultas listas para enviar
- Cantidad de errores
- Tasa de error
- Tasa de aprobación
- Observaciones operativas

## Propósito del panel

El dashboard permite:

1. Supervisar el estado general del flujo.
2. Validar cuántos casos fueron procesados por IA.
3. Controlar cuántos casos avanzaron luego de revisión humana.
4. Medir errores detectados durante la prueba.
5. Mostrar una vista pública específica sin exponer toda la base completa.

## Relación con la rúbrica de evaluación

Este archivo respalda el criterio:

**Dashboard de control (20%)**: enlace público a una vista compartida de Airtable para monitorear KPIs y tasa de errores del sistema.

## Seguridad y privacidad

El dashboard trabaja únicamente con datos ficticios de prueba. No expone información real de alumnos, correos reales ni datos institucionales sensibles.

El enlace compartido corresponde a una vista específica de métricas y no debe utilizarse para exponer información operativa real.
